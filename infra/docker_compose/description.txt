Все контейнеры, кт необходимо запустить:
1) Контейнер бэкенда  nobugsme/nbank:with_validation_fix //бекенд 4111 (порт внутри кон-ра) -> 4111 (порт снаружи кон-ра)
   ("внутри" - т.е.порт на кт поднимается сервис)

2) Конт фронтенда  nobugsme/nbank-ui:latest //фронтенд 80 (только внутри)

3) Конт nginx   nginx:latest //nginx 80 (внутри) -> 80 (снаружи)

4) Конт Selenoid  aerokube/selenoid:latest  //selenoid 4444 (внутри) -> 4444 (снаружи)

5) Конт Selenoid UI  aerokube/selenoid-ui:latest  // selenoid ui 6567 -> 8080??
   мож поднять на любом порту...

Шаги по внедрению Docker Compose:

1) Создать docker-compose.yml файл
2) В этом файле описать каждый из докер контейнеров,
   а именно: образ, порт, последовательность запуска, общая докер сеть)
3) Написать скрипт по поднятию всех докер контейнеров с помощью docker compose
